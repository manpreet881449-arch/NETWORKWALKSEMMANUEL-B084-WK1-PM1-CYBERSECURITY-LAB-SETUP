
# NETWORKWALKSEMMANUEL-B084-WK1-PM1-CYBERSECURITY-LAB-SETUP

## Purpose of the Lab

The purpose of this lab is to prepare an isolated virtual environment for cybersecurity learning and authorized security testing.

The lab will help me understand:
- Virtual machine configuration
- Kali Linux environment setup
- Virtual networking
- Basic network troubleshooting
- Cybersecurity lab documentation

**Important:** Testing will only be performed on systems I own or have explicit permission to test.

## Lab Architecture

The lab environment uses VMware Workstation to run Kali Linux as a virtual machine.

### Components
- Host Operating System: Windows
- Virtualization Platform: VMware Workstation
- Security Operating System: Kali Linux 2026.2
- Virtual Network Adapter: Custom (VMnet2)

## Lab Configuration

| Component | Configuration |
|---|---|
| Hypervisor | VMware Workstation |
| Security OS | Kali Linux 2026.2 |
| Allocated RAM | 2048 MB |
| Processors | 4 |
| Virtual Disk | 80.1 GB |
| Network Adapter | Custom (VMnet2) |

## Lab Setup Procedure

### Step 1: Prepare VMware
Open VMware Workstation and start the Kali Linux virtual machine.

### Step 2: Configure Virtual Machine
Review the assigned memory, processor, disk, and network adapter settings.

### Step 3: Start Kali Linux
Start the virtual machine and verify that the Kali Linux desktop loads successfully.

### Step 4: Verify Network Connectivity
Check the network configuration and connectivity from within Kali Linux.

Add the actual commands and results after performing verification.
